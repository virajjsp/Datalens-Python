# Datalens-Python
DataLens is a lightweight, pure Python utility designed to demonstrate core array manipulation, collection analytics and algorithm optimization. This tool implements custom sorting partitions, ordered duplicate removal and performance benchmarks comparing Python lists and sets all without relying on external third-party libraries.
DataLens: Array & Collection Analytics Engine
The project is structured into two main components:
1. datalens.py : The core logic module containing pure algorithmic functions for data structures and array techniques.
2. main.py : An interactive command-line interface that allows users to test, visualize, and interact with the data engine in real time.

Syllabus Mapping & Concepts Covered
Unit 1: Efficiency of Algorithms & Time Complexity Tradeoffs.
Unit 2: Modular Programming, Function Definitions, Parameters, and Arguments.

Step-by-Step Setup & Installation Guide

Follow these instructions carefully to set up and run the project locally on your machine.

Step 1: Environment Setup (Python Installation)
Ensure you have Python 3 installed on your system. You can verify your installation by opening your terminal (or command prompt) and running.

Step 2: Clone the Repository
Clone your GitHub repository to your local machine using Git.

Step 3: Dependency Installation
DataLens is built entirely using Python's native built-in libraries (such as time), meaning no external package installation (like pip install) is required. Everything needed to run the project comes built into standard Python 3.

Step 4: Configuration
No external configuration files (like .env or config JSONs) are required for this project. The application uses a default working dataset built directly into the script, which users can interact with immediately upon execution.
